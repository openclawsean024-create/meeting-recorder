把 MeetingFlow 帶進視訊會議

Chrome Manifest V3 外掛可錄製目前的 Google Meet、Zoom Web 或其他瀏覽器分頁音訊。錄音留在你的裝置，停止後下載 WebM，再拖進工作台產生逐字稿與行動項。

開發版安裝

  1. 下載 GitHub repository。
  2. Chrome 開啟 chrome://extensions。
  3. 開啟「開發人員模式」。
  4. 點「載入未封裝項目」，選擇 extension/ 資料夾。
  5. 把 MeetingFlow 固定到工具列。

錄製流程

  1. 進入視訊會議瀏覽器分頁。
  2. 點外掛並勾選「已告知與會者」。
  3. 開始錄製目前分頁。
  4. 停止後保存至 IndexedDB 並下載 WebM。
  5. 回到 MeetingFlow 上傳音檔。

外掛使用 Chrome tabCapture、service worker 與 offscreen document；不支援原生 Zoom 桌面程式，也不會繞過平台或系統權限。
